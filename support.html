支援與常見問題

最後更新：2026 年 5 月 24 日

找不到答案？來信：alex.yeh@angelz13.com（通常 1-2 個工作天內回覆）

1. 如何取得 OpenAI API key？

App 內的 AI 解讀功能需要您自帶 OpenAI API key。首次設定約 5 分鐘、需綁信用卡：

  1. 到 platform.openai.com/signup 註冊 OpenAI 開發者帳號（與一般 ChatGPT 帳號為不同入口）
  2. 登入後左側點 Billing → 加信用卡 → 首次儲值 ≥ 美金 5 元
  3. 左側點 API keys → Create new secret key → 命名「Tarot iOS」→ 複製整串（以 sk- 開頭）
  4. 回到 App 進「⚙️ 設定」貼上、按儲存、按「測試連線」確認綠燈

單次 AI 解讀成本約美金 0.01-0.05（依模型選擇與牌陣大小）。

2. AI 解讀沒回應或報錯怎麼辦？

  • 連線錯誤 / Timeout：確認網路通暢、再試一次。AI 解讀預設 60 秒 timeout。
  • 401 Unauthorized：API key 錯誤或失效。回設定頁重貼一次、按「測試連線」確認。
  • 429 Too Many Requests：超過 OpenAI 速率限制、稍候 1 分鐘再試。
  • 402 / Insufficient quota：OpenAI 帳號餘額用罄、回 platform.openai.com 加值。
  • 5xx Server Error：OpenAI 端服務暫時異常、稍候再試。

3. 抽牌紀錄不見了？

抽牌紀錄存於 iOS 系統的 Capacitor Preferences 沙盒。以下情況會清空：

  • 解除安裝 App（再裝回不會還原）
  • 於 iOS 系統「設定 → 一般 → iPhone 儲存空間 → TAROT → 卸載 App」（保留資料）vs「刪除 App」（清空資料）
  • 於紀錄頁手動逐筆刪除

本 App 不提供雲端備份（為符合「資料只在本機」的隱私承諾）。如需保留珍貴紀錄，建議定期截圖。

4. 怎麼還原 NT$30 解鎖？

換新手機、重灌 App、或更換 Apple ID 後想還原已購買的「專家模式」：

  1. 確認目前登入的 Apple ID 與當初購買時相同
  2. 進「⚙️ 設定」→ 點「還原購買 (Restore Purchases)」
  3. 等系統驗證、解鎖狀態回復

Apple 規定 non-consumable 購買終身可還原、無額外費用。

5. 我可以離線使用嗎？

抽牌、查看 78 張牌的關鍵字、紀錄、每日提醒都可在無網路下使用。

但 AI 解讀必須連線（App 連線到 api.openai.com），無網路時請改用「複製 Prompt」按鈕、上線後再貼到其他 LLM。

Support & FAQ

Last updated: May 24, 2026

Can't find what you need? Email alex.yeh@angelz13.com (response within 1-2 business days).

1. How do I get an OpenAI API key?

AI reading requires you to bring your own OpenAI API key. First-time setup takes ~5 minutes and requires a credit card:

  1. Sign up at platform.openai.com/signup (this is the developer portal, separate from ChatGPT)
  2. In the left sidebar, click Billing → add a credit card → top up at least USD $5
  3. Click API keys → Create new secret key → name it "Tarot iOS" → copy the full string (starts with sk-)
  4. Back in TAROT, go to "⚙️ Settings", paste the key, tap save, then tap "Test connection" to verify

Each AI reading costs roughly USD $0.01-0.05 depending on model and spread size.

2. AI reading not responding or showing errors?

  • Connection error / timeout: check your network and retry. AI reading has a 60s timeout.
  • 401 Unauthorized: invalid or expired API key. Re-paste in Settings and tap "Test connection".
  • 429 Too Many Requests: OpenAI rate limit exceeded. Wait 1 minute and retry.
  • 402 / Insufficient quota: OpenAI account balance depleted. Top up at platform.openai.com.
  • 5xx Server Error: OpenAI service issue. Wait and retry.

3. My draw history is gone?

Draw history is stored in iOS Capacitor Preferences sandbox. It is cleared when:

  • You uninstall the app (reinstalling does NOT restore data)
  • You "Delete App" (vs "Offload App" which preserves data) in iOS Settings → General → iPhone Storage
  • You delete entries individually in the history page

This app provides no cloud backup (to honor the "data stays on device" privacy promise). For valuable entries, please screenshot.

4. How do I restore my NT$30 unlock?

After a new phone, reinstall, or Apple ID change, restore your "Expert Mode" purchase:

  1. Verify you are signed in with the same Apple ID used for purchase
  2. Go to "⚙️ Settings" → tap "Restore Purchases"
  3. Wait for system verification — unlock state will be restored

Apple non-consumable purchases are restorable for life at no additional cost.

5. Can I use the app offline?

Drawing cards, viewing 78-card keywords, history, and daily reminders all work offline.

However, AI reading requires internet (the app connects to api.openai.com). When offline, use the "Copy Prompt" button instead and paste into another LLM later.
